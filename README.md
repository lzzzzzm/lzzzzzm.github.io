# Zhimin Liao — Academic Homepage

Personal academic homepage for Zhimin Liao (廖智民).

## Preview

Open `index.html` in a browser, or serve this directory with a local static HTTP server.

## Edit

- `index.html`: biography, publications, awards, and links.
- `styles.css`: typography and responsive layout.
- `script.js`: animation controls and citations.
- `assets/`: portrait, logos, paper first pages, and research animations.
- `Zhimin_Resume.pdf`: downloadable CV.

## Publish

In repository Settings → Pages, select GitHub Actions as the publishing source.
Push changes to `main`. The included workflow publishes the static site to
https://lzzzzzm.github.io/.
